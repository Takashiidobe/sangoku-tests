# sangoku-tests

Compare Sangoku and SDCC codegen for paired Rust and C probes on SM83. The suite
measures function bytes, fixture helpers, and linked dependencies where
available. Both optimization modes measure static code size. Host semantic
checks are separate from the codegen suite.

## Run the suite

Install Python 3.10+, SDCC (`sdcc`, `sdar`, and the SM83 library), and RGBDS
(`rgbasm`, `rgblink`, `rgbfix`). Build Sangoku with `cargo build --release` in
`../sangoku`, or pass `--sangoku PATH` to use another driver.

```bash
python3 tools/compare.py
python3 tools/report.py
```

The suite writes `results/comparison.json` and caches compiler artifacts under
`build/sangoku-cache/`. Pass `--no-cache` to rebuild. Use `--list` to find case
IDs, then run a smaller comparison with `--case u16_div3 --modes size`.

## Check a compiler change

Save a baseline before the change. Rebuild Sangoku after the change, then run
the same corpus and compare the two reports.

```bash
python3 tools/compare.py --output results/before.json
# rebuild Sangoku after your change
python3 tools/compare.py --output results/after.json
python3 tools/report.py results/after.json --baseline results/before.json
```

The report shows size changes per case in both modes and flags missing results.
Changed Rust fixtures are listed and skipped. Add `--max-growth 0` to fail on
any byte growth or lost result, or set a higher allowance in bytes per
measurement. For a partial comparison, use `--mode` or `--case` to select the
same subset in both reports.

## Read the results

See the generated [per-case codegen catalog](#per-case-codegen-catalog) for
fixture coverage and findings. Refresh it from a full comparison report with
`python3 tools/update_readme.py` (requires Prettier).

Body sizes use size mode (`z` versus `--opt-code-size`); a signed delta is S
minus C. A speed-mode value appears only when body or measured dependency sizes

These are static symptoms, not established optimizer root causes or timing
results. Body bytes exclude helpers and include native ABI costs. String/memory
and libc-style pattern rows also give isolated helper-inclusive totals.

Standalone integer/float Rust helper totals are unavailable. Call fixture
callees are measured separately; their callees and runtime helpers are not
included in caller body bytes.

frame setup. SP references count source instructions, not spills.
